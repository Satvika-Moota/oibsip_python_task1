#  Voice Assistant Using Python
This is a simple **Python Voice Assistant** that can listen to your voice, understand commands, and reply back using speech.
It is a beginner-friendly project made to learn how real voice assistants like Alexa or Google Assistant work.

##  Features
* 🎤 Takes voice commands from the user
* 🔊 Converts text responses into speech
* 🕒 Tells current time and date
* 🌐 Can open websites like Google, YouTube, etc.
* 💬 Responds to basic questions
* 🖥️ Simple GUI using Tkinter

##  Technologies Used
* **Python**
* **SpeechRecognition** – to recognize voice
* **pyttsx3** – for text to speech
* **Tkinter** – for GUI
* **Datetime** – for time & date

## ⚙️ Installation

1. Clone this repository:
git clone https://github.com/your-username/voice-assistant.git

2. Go to the project folder:
cd voice-assistant

3. Install required libraries:
pip install -r requirements.txt

##  How to Run
python yourfilename.py

## Make sure your microphone is working properly.
